# 열섬 위험 지수 (발표·설명용)

`web/js/heat.js` 에서 브라우저가 직접 계산합니다. 외부 API 없이 **V-World 건물 + 연속지적도**만 사용.

## 계산
5m 격자 칸마다, **주변 반경 50m(10칸) 평균**으로:

```
원점수 = 0.45 × 포장면 비율   (도로·인도·대지·건물 지붕)
       + 0.20 × 건물 덮개 비율
       + 0.15 × 건물 높이(8칸=40m 이상이면 1)
       − 0.45 × 녹지 비율     (공원·임야 1, 밭·풀밭 0.6)
       − 0.30 × 수면 비율     (하천·구거)
```
원점수를 0~100점으로 펼침 (시가지 값이 몰린 0.15~0.55 구간을 40~100점으로 넓게).

| 점수 | 단계 |
|---|---|
| 85+ | 매우 높음 |
| 70~84 | 높음 |
| 45~69 | 보통 |
| ~44 | 낮음 |

## 근거 (발표 멘트)
- 도시 지표면 온도는 **불투수면(포장·지붕) 비율이 높을수록 올라가고**, **녹지·수면 비율이 높을수록 내려간다**는 관계가 국내외 연구에서 반복적으로 보고됨.
- 고층·고밀 건물은 바람길을 막고 밤에 열이 빠져나가지 못하게 함.
- 이 지수는 **PoC용 단순 모델**. 다음 단계로 위성 지표온도(Landsat 열적외선)·기상청 기온으로 가중치를 보정할 수 있음.

## 화면
- 상단 `🌡️ 열섬 지도` 버튼으로 켜고 끔. 주소 끝에 `?heat` 를 붙이면 켜진 채로 시작 (시연용).
- 지도에서 위치를 누르면 "이 주변 열섬 지수 88 · 매우 높음" 표시 → 그 자리에 🌳 가로수 제안.

## 시민 제안 시뮬레이션 (완료)
- 제안 유형마다 효과(녹지·수분·포장면·지붕)와 영향 범위가 정해져 있음 (`types.js` 의 `effect`)
- 위치를 누르고 유형을 고르면 **"놓으면 이 주변 지수 46 → 37 (−9)"** 미리보기 + 초록 사각형으로 영향 범위 표시
- `✨ 제안 효과` 버튼: 지금까지 모든 시민 개선 제안이 실현됐을 때의 열섬 지도로 바꿔 그림
- 리포트 패널: **영향권**(지수가 0.5 이상 내려간 곳)의 면적과 평균 변화. 무실동 전체 평균은 면적이 커서 변화가 묻히므로 영향권 기준으로 말함
