# 파트 2 — 3D 맵 A: 렌더링·성능·카메라

담당 파일: `web/js/map.js`, `web/js/markers.js` (+ `web/js/app.js`의 카메라·루프 부분)

현재: 지면은 칸마다 색칠한 텍스처, 건물은 칸마다 기둥 하나(InstancedMesh), 블록 테두리는 셰이더로 그림.

## 참고
- 월드 좌표 1 = 격자 1칸. 칸 (x, z) 중심 = (x+0.5, 높이, z+0.5)
- three.js는 `web/vendor/`의 r160 고정. 다른 버전 섞지 말 것
- 성능 확인: 크롬 개발자도구 → 기기 모드(iPhone) + Performance 탭

## 11/8 렌더링 개선 (완료)
- 그림자(태양 남서쪽), 건물 벽/지붕 색 분리, 층마다 창문(셰이더), 건물 아래 음영, 하늘 그라데이션
- 공원·임야에 복셀 숲, 도로변 인도에 가로수 (`map.js`의 `buildTrees`)
- 느린 기기 자동 저사양 모드: 처음 60프레임 평균이 40ms 넘으면 그림자 끄고 해상도 1배. 주소 끝에 `?low` 붙이면 강제
- 다음 후보: 도로 중앙선, 원주시청 등 랜드마크 이름표, 밤 모드(창문 불빛)
