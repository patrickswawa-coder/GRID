# 파트 3 — 3D 맵 B: 민원 등록 UI·사용성

담당 파일: `web/index.html`, `web/css/style.css`, `web/js/app.js`(카메라 제외), `web/js/types.js`

현재 흐름: 지도 탭 → 아래에서 등록 시트 → 유형 6개 중 선택(반투명 미리보기 블록) → 의견 입력 → 등록 → 블록 떨어짐 + 토스트.
기존 민원 아이콘 탭 → 상세 카드 + 공감 버튼.

## 참고
- 탭과 드래그 구분: 8px 이내·0.6초 이내 움직임만 탭
- 건물 벽을 누르면 벽 앞 칸(길 쪽)이 선택됨, 옥상을 누르면 옥상 칸
- 등록 시트가 열리면 `camera.setViewOffset`으로 화면을 위로 올려 선택한 칸이 가려지지 않게 함
- 유형을 추가/변경하면 백엔드·대시보드와 같이 바꿔야 함 (CONVENTIONS 5장)
