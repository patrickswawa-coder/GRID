# 11/09 변경 정리 (팀원 공유용)

11/09에 머지된 큰 변경과, 받아서 쓰는 방법을 정리했어요. 자세한 내용은 각 PR 설명에 있어요.

## 받는 법
```bash
git checkout main
git pull
```
수정할 때는 지금처럼 **브랜치 → PR** (`main`에 직접 push 금지, `CLAUDE.md` 참고).
웹 화면만 볼 때는 `cd backend && SERVE_WEB=1 AI_ENABLED=0 uvicorn main:app --reload` → http://localhost:8000

## 주소 (HTTPS 적용됨)
| | 주소 |
|---|---|
| 시민 화면 | https://grid-team7.duckdns.org/ |
| 관리자 화면 | https://grid-team7.duckdns.org/admin/ |

- 예전 `http://32.190.9.9` 는 자동으로 위 주소로 넘어가요.
- 관리자 비밀번호는 바꿨어요 (단톡방 말고 개인적으로 물어봐 주세요).

## 시민 화면에서 바뀐 것
- **거리 QR 위치 모드** (#31): QR 주소 `?at=위도,경도&name=장소` → 안내 없이 그 자리로 이동, 📍지금 계신 곳 핀, **[이곳에 의견 남기기]** → 유형 선택 → 등록 (글은 선택, 빠른 문구 버튼)
- **📍 내 위치** 버튼 (#37): HTTPS에서만 보임 (http에선 브라우저가 위치를 막음)
- 열섬 지도 **기본으로 켜짐**, 처음 화면은 시가지 중심, 제안 창 칩에 `구역 H9` 대신 장소 이름, 도움말에 열섬 지수 계산법·한계
- 지도 가장자리 지점(시외버스터미널)은 지도 안쪽을 바라보게 카메라를 돌림 (#37, #39)

## 데이터·정확도
- **좌표 변환 수정** (#36): 지도는 EPSG:5186(TM) 격자인데 앱은 단순 비례식이라 **15~38m 어긋나 있었음** → `web/js/geo.js`, `backend/geo.py`(같은 공식)로 교체
  - 민원 위경도는 이제 **서버가 칸(x, z)으로 계산** (관리자 지도 위치 정확)
  - `voxels.json` meta 의 `tm`(격자 원점)이 필요해요. **`data/build_voxels.py` 로 지도를 다시 만들면 자동으로 들어가요** (지도 파일을 손으로 고치지 말 것)
- 우선 개선 구역 점수: 열섬 항목을 **구역 평균**으로 (#23) — 예전엔 상위 10% 값이 100에서 포화돼 6곳이 동점이었음

## 백엔드
- 도배 방지는 **기기(X-Client-Id) 기준** (#37): 시연장 같은 와이파이 여러 명이 같은 자리·유형으로 등록해도 안 막힘. IP는 분당 60건 상한
- 의견 글은 선택 (비우면 "그늘막 요청"처럼 저장)
- AI 정책 제안: 자료에 없는 원인(교통량 등) 추측 금지, 순위 그대로, '추정' 표현 (#23, #27)

## QR 포스터
`docs/qr/` 에 최종 3장 (발표 자료에 그대로 써도 돼요)
| 장소 | 지수 | 그늘막 하나 효과 |
|---|---|---|
| 시외버스터미널 앞 | 95 | −2.7 |
| 시네프라자 앞 상가거리 | 94 | −3 |
| 무실초등학교 앞 | 92 | −3 |

- 다시 만들기: `python data/make_qr.py https://grid-team7.duckdns.org/ --spots data/qr_spots.csv` → `data/qr/`
- 장소를 바꾸려면 `data/qr_spots.csv` 에 **포스터를 실제로 붙일 곳의 좌표**(네이버 지도 우클릭 → 좌표 복사)를 넣기
- ⚠️ 지수가 **100인 칸은 피하기**: 포화 구간이라 제안을 놓아도 숫자가 안 내려가서 시연에서 "변화 없음"이 뜸

## 서버 배포 (main 에 머지한 뒤)
```bash
ssh -i hackathon-e5-t07.pem ubuntu@32.190.9.9      # 내 PC 에서
cd ~/GRID && git pull --ff-only                      # 여기부터 서버 안 (ubuntu@...$)
~/GRID/deploy.sh                                     # "배포 완료" 가 뜨면 끝
```
- 시연 데이터 넣기: `deploy/README.md` 의 "시연 전 데이터 초기화 + 더미 민원"
- HTTPS 설정은 이미 끝났어요 (`deploy/enable_https.sh`). `setup_server.sh` 를 다시 돌려도 유지됨
