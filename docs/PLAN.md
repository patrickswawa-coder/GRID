2. 어두운 골목을 눌러 💡 가로등 블록 배치 + "밤에 무서워요" 등록 → 블록이 떨어지는 애니메이션

4. AI 요약: "C3 구역에 가로등 요청 집중, 우선 검토 필요" → "예산 집행 근거"로 마무리

## 위험 요소와 대비

| 위험 | 대비 |
|---|---|
| 시연장 와이파이 불안정 | three.js는 `web/vendor/`에 포함(CDN 안 씀). 폰 핫스팟 준비. 시연 영상 백업 |
| 실제 SHP 변환이 늦어짐 | 임시 샘플 맵이 이미 동작 — 11/10까지 안 되면 샘플로 발표 |
| Bedrock 호출 실패 | 자동으로 통계 기반 요약으로 대체됨 (`ai:false`) |
| 저가 폰에서 버벅임 | 맵 범위 줄이기(`--bbox`), 칸 크기 키우기(`--cell 8`) |
